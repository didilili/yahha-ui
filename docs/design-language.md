# 设计语言

Yahha UI 是一套漫画手账风 React 组件库，面向个人博客、个人主页与内容网站。品牌愿景是「一起做，全宇宙最可爱的 UI 组件库」，长期标语是「把可爱，搭进你的世界」。网站的虚构场景叫「Yahha 星球」：朋友们在草地上留一个位置，等朋友回来，分一块点心，帮迷路的星星找路。宇宙承载愿望，星球安放日常，天真烂漫来自朋友之间具体的小动作。

基础组件延续“漫画手账”语言：清楚的暖墨轮廓、像软团按扣一样饱满的主操作、平整白纸内容面，以及清亮粉色与浅蓝纸边。不同组件按用途分出按钮、纸签、字段、栏目与便笺，让文章、照片和人的表达占据主要位置。角色通过共同活动、探头和章节小图案参与网站，基础组件自身保留完整的轮廓、排版和状态。正式产品名为 Yahha UI，Yahha 星球是承载这些场景的想象空间。品牌与文字的使用规则见[组件文档规范](documentation.md#品牌与文案)。

## 品牌、组件与素材的分工

- **站点品牌层**：`playground/src/site/` 负责天空色首页、草地分区、朋友群像、文档探头页头与花芽等章节图案。天空表达欢迎，草地承接互动小站，白色内容面承载阅读；这些场景色使用站点语义变量，不加入基础组件的默认背景，也不覆盖组件内部样式。
- **基础组件层**：`src/` 负责暖墨、清亮粉色、白底字段、纸签、平面内容面及其状态。操作区域用清楚的 2px 深墨轮廓，内容容器和普通纸签用较轻的蓝灰纸边；强调、选中和错误各有语义。安装包仅引入组件样式时，也应保持这套层次。
- **角色与素材层**：展示素材集中在 `playground/src/examples/scenes/artwork/`，由首页、文档外壳或场景示例按需引用，不进入 `src/` 和默认 npm 产物。当前朋友群像与探头图保留 v3 造型，后续人物细修单独评审；历史版本、人物研究和撤回记录只保留在开发预览。三位朋友共同出现，不承担顶栏三套全站配色切换。

首页首屏保留一处主要群像，文档标题区可使用一处探头构图；同一区域不重复堆叠完整角色。花、嫩芽、星光等小图案参与入口识别或章节转折，每个章节标题最多放一组辅助图案。正文段落、字段内部、代码与 API 表格保留清楚的阅读和操作区域。错误、必填、选中和加载等必要信息由文字、图标及原生语义表达，角色不承担唯一说明。

官网首页、组件总览、指南与全部组件文档统一应用清亮的漫画小站视觉：天空蓝承担外部环境与标题场景，白色承载阅读和真实演示，粉色纸签标记当前导航与案例标题，黄色小签辅助分类。暖墨轮廓集中于页头和重点入口，示例边界使用蓝灰细线，源码使用独立浅蓝底；不继续叠加大面积奶黄、灰绿和米白。文档页头复用一处朋友探头与云朵、星光、花的完整构图，短标题同排、长标题自然换行，手机将场景移至标题下方；首页保留独立的欢迎场景，总览保留筛选与真实组件小样。`docs-cartoon` 仅组织站点外壳，不修改基础组件 token、尺寸或交互，不把场景装饰复制进演示源码和安装包。顶栏按实际路由标记首页、开始使用、组件或设计与组合，侧栏保留独立滚动内层与四周留白，右侧目录使用墨点和加粗文字标记当前章节。

组件总览延续同一套天空页头、朋友探头和章节花芽，按现有八组组织真实小样，并单列 ThemeProvider 主题配置。预览纸面负责展示，标题链接负责进入示例与 API；小样不参与键盘顺序或状态播报，也不缩放控件、自动打开浮层或复制另一套外观。桌面、手机分别排布，搜索、分类和清空复用现有组件；返回后保留筛选上下文。组件目录和分类顺序与侧栏共用数据，阅读、文章编辑和完整博客的入口指向现有指南。

桌面首页由标题、行动入口与群像共同构图；手机将文字和场景重新排布，优先保留朋友之间的关系及主要入口，减少次要装饰。人物、长耳与道具应完整可辨，装饰不得遮住文字、焦点圈或浮层，也不进入键盘顺序；纯装饰图片使用空 `alt`。场景动效有明确起止，遵循减少动效设置。

欢迎场景把环境与招呼分开：云缓慢漂移、草芽和小花围绕根部轻摆，地面、文字和内容卡片保持稳定；小八前爪挥两下便回到原位。环境循环提供可见的暂停入口，暂停冻结当前帧，继续沿原进度播放；再次招呼只重播前爪。首次主要画面可见后启动，离屏与页面后台暂停，系统减少动效时呈现完整静帧。手机减少次要植物和远云的运动，不缩小操作目标。该场景属于网站与示例素材，不进入基础组件默认产物。

## 尺度规范

[设计规范页](http://127.0.0.1:4175/#/guides/design-baseline) 直接展示本库默认组件。此前的左右候选对照已撤回：不再通过示例 CSS 另设一套平面主题。它包含表单状态、按钮尺寸和完整阅读；原始 TSX 与页面同源。

- **常规单行控件**：Button、IconButton、TextField、Select 以 44px 为默认对齐基准。Button / IconButton 已有 `sm / md / lg` 对应 36 / 44 / 52px；其余组件没有因此新增 `size` API。
- **控件文字**：紧凑、常规、宽松字阶为 12 / 14 / 16px，行框为 16 / 20 / 24px。字段在手机或粗指针环境使用 16px / 24px 字阶，同时调整上下内边距，常规高度仍为 44px。
- **盒模型**：上下内边距由 `(目标高度 − 行框 − 上下边框) / 2` 推导，不只改 `min-height`。长 Button / Select、多行选项与标签允许增长；不得用固定高度、截断或缩小文字维持数字。
- **内容与辅助文字**：Text 的 `sm / md / lg` 为 14 / 16 / 18px，默认正文 16px、行高 1.8。表单标签和紧凑反馈通常使用 14px，字段提示与状态纸签可使用 12px。正文与控件分别使用 body、control 语义 token。
- **标题**：h1–h6 默认字号依次为 32 / 24 / 20 / 18 / 16 / 14px，行高 1.45。先选正确语义层级；h2 的短曲线仍是默认装饰，不能为了获得装饰而跳过标题层级。
- **间距**：共享尺度采用 4px 基础步长，常用 4 / 8 / 12 / 16 / 20 / 24 / 28 / 32px。曲线、勾、圆点、箭头等局部图形按其几何关系保留微调，不强塞进布局间距。
- **图标**：文字按钮的 SVG 图标随 `sm / md / lg` 使用 16 / 18 / 20px 图框；IconButton 使用 18 / 20 / 22px 图框。字段前图标与 Select 展开图标使用 18px 图框。保留原始 `viewBox` 与长宽比，圆端笔触在同族中保持一致；按图形重心检查视觉居中，不通过拉伸或改变控件高度迁就图标。自定义文字、表情和其他插槽内容不按 SVG 图框强制缩放。
- **点击目标**：Checkbox / Radio 的 22px 标记、Switch 的 50×30px 轨道属于视觉图形，普通操作行至少 44px。Tabs、Pagination、菜单和 Select 选项至少 44px；SegmentedControl 单项 44px，托盘总高度另计。Badge、Avatar、图片、Skeleton 和文章容器不套单行控件高度。
- **多行输入**：Textarea 保留 `rows`、内容和纵向调整能力。单行 `rows=1` 可与常规字段对齐，多行不限制为 44px。

这些数值是本项目为轻量内容站点与现有 API 作出的选择，并不是主流库的统一数值。Ant Design 默认控件 32px，Radix 默认 TextField 在 100% 缩放下也是 32px，Animal Island 的 Input 默认 40px；参考的是共享 token、尺寸分档和盒模型推导的方法。

W3C 的 WCAG 2.2 AA 点击目标基准为 24×24 CSS px、AAA 增强基准为 44×44，均有例外。点击目标、视觉图形与组件整体高度分别验收；36px 紧凑按钮不能据此宣称满足 AAA。主要触屏操作优先常规或宽松尺寸。

## 颜色与文字

- 默认视觉选用吉伊粉色预设（`chiikawa`），通过 `ThemeProvider theme="chiikawa"` 设置：内容面和字段为白色 `#ffffff`，暖墨正文为 `#49313d`，深墨轮廓为 `#684150`，粉色强调为 `#ffc3d9`，悬停为 `#ffb3cf`，轻量强调为 `#fff0f6`。次要文字 `#7a5c6d` 降低强调，保留清楚的可读性。
- 常规主题边线为 `#c58ba1`，焦点为 `#b04e78`；中性纸面为浅蓝白 `#f1f8ff`，轻纸边为蓝灰 `#c9deec`，禁用面为 `#f0f3f7`。白色承担内容，粉色承担操作和选中，蓝灰承担轻纸边；成功、警告和错误仍使用各自语义色。
- 小八浅蓝预设（`hachiware`）和乌萨奇浅黄预设（`usagi`）在 ThemeProvider 文档中单独展示。组件尺寸、语义和状态保持一致；文档站不通过顶栏全站换色来展示设计语言。
- 使用公开 `ThemeTokens` 覆盖颜色，Portal 同步最近 Provider 的预设与颜色。显式传入 `tokens.line` 时，常规边线、深墨轮廓、轻纸边及按压底边一起覆盖，加载占位的底色独立保留。尺寸、圆角与动效变量是库内部实现，不作为公开定制接口。
- 正文优先使用清楚的系统字体与适合连续阅读的行高。组件继承使用方字体，不自动加载手写字体；手写字体可用于少量标题或情境文字，不能成为整库使用前提。

`theme` 仍为必填属性，“默认视觉”指推荐的配色选择，不表示可以省略 Provider 配置。

## 轮廓与层次

轮廓保持圆钝、清楚和轻微不对称。深墨线用于建立结构，纸色与强调色用于分出轻重；不会给每个组件都添加厚边、投影或装饰。

- **按钮与按扣**：Button 的默认轮廓为 `22px 28px 24px 23px / 52% 48% 52% 48%`，使用 2px 深墨线；三档尺寸保留各自水平圆角，共用上下弧线比例。主按钮有主题粉色面、细亮边、内底边和 3px 硬底边，按下时底边收短；secondary 是白色描边和浅蓝内底边，ghost 保持轻量。选中使用内凹墨线，与悬停和焦点分别表达。IconButton 复用同一语法，关闭等辅助动作使用 ghost。首页主要导航链接延续共享动作轮廓、底边与反馈变量，同时保留原生链接语义。
- **白底字段**：TextField、Textarea、Select 的触发器采用 `12px 16px 14px 11px` 的长框、2px 深墨线与白底，默认使用浅蓝内底边，不带外投影；只读和禁用去除内底边；错误内缘使用独立语义色并优先于只读，禁用仍保持平整。标签、提示与错误说明统一 4px 水平文字留白和上下节奏。Textarea 仍由 `rows`、文字与纵向调整决定高度，多行不套用固定 44px。TextField 的前图标随焦点和错误状态调整墨色；Select 展开时通过浅色面与边线说明打开状态，错误边线保持更高优先级。只读和禁用各有独立表现。
- **选择与内容导航**：SegmentedControl 将值选项放在轻纸边托盘中，托盘边框保持 2px，选中纸片有更清楚的墨边和轻内凹，悬停与焦点不抹去选中标记；Tabs 没有外托盘，当前项用浅粉纸面、白色内缘和下方短墨线标记。Pagination 的普通页码使用轻纸边与浅蓝内底边，当前页使用粉色墨圈与内缘，数字和文字在各自按钮内居中；Accordion 保持轻纸线分隔的开放行，可用的展开标题带浅粉纸面和白色内缘，28px 小圆扣对齐问题第一行，以浅蓝和粉色区分收起与展开。
- **纸签与白纸内容**：Badge 使用 `7px 11px 8px 6px` 的小纸签轮廓；neutral 用浅蓝白纸面、轻纸边和细内边，accent 用粉色实色纸面与清楚墨边，成功态保持绿色与小勾，并以细虚线表现纸章。Surface 使用 `22px 30px 25px 20px` 的平面轮廓、1px 轻纸边与 24px 默认内边距，不带投影或悬停动作。深墨操作边与轻纸内容边分工，正文按阅读顺序开放排布，不逐段包进卡片。
- **小选项与原生形状**：普通菜单项采用 `8px 12px 9px 7px` 的小纸片轮廓；Select 选中行使用 `9px 15px 11px 8px` 的粉色纸片、内边和白底小纸章勾，键盘高亮另用内部焦点轮廓，禁用行保留可读说明；三个状态可以同时辨认。RadioGroup 的圆形选中标记保留白色内环，选中行用轻纸色和内底缘，未选可用项悬停使用浅蓝色；Switch 轨道内底缘与白圆扣细影只改变绘制，禁用时取消层次；SegmentedControl 纸托盘和选中纸片通过细内缘分层，全部阴影保留在既有间距之内。Checkbox 的 22px 方形采用 `7px 8px 7px 6px` 圆角与轻内边，保留墨勾和半选短横；Radio 保留圆形与实心点，Switch 保留轨道和圆钮。选中标记不会被统一成按钮外形。

- **便笺、对白与信笺浮层**：Select 使用 `13px 22px 18px 11px` 的便笺轮廓、蓝灰纸边和轻纸层次；DropdownMenu、Popover 保留 `14px 20px 17px 12px` 的便笺轮廓，纸面内底边用 3px 浅蓝与既有轻投影分层；可用菜单高亮行补白色上内缘，键盘焦点继续独立表达。Tooltip 使用 `17px 22px 19px 12px / 12px 16px 14px 8px` 的椭圆角短对白，纵向弧角为箭头连接留出直边；采用白底和浅蓝内底边，保留 10px 独立箭头与 -4px 接缝位置，箭头与内容面共用颜色，不能留下漏线。Dialog 使用更饱满的椭圆角信笺形状和浅蓝内底边，集中承载当前任务。页脚以浅蓝纸面、paper-line 分隔与 16px / 12px / 12px 内留白组织操作，长按钮自然换行；整个弹窗保持原有短屏滚动，页脚不悬浮遮挡正文。轻浮层使用 3px 纸边和轻投影，Dialog 使用 4px 纸边与更宽投影；内容面与浮层有明确差别。强制颜色下清除新增装饰阴影，边框、文字与焦点继续使用可见的系统绘制。
- **持续说明与短结果**：Alert 保留语义色的平面说明纸，白色上内缘与浅语义色下内缘只增加纸面层次；Toast 使用白纸回执、状态印签和轻浮层投影，浅蓝内底边与操作区纸面延续同一套轻纸边。两者的图标、文字与操作各有位置，不依靠角色表情表达成功或失败。

2026-10-29 已确认：TextField、Textarea、RadioGroup、Switch、SegmentedControl 采用上述内缘细化作为正式版本。随后探索的整行信签边框、开关勾号与虚线分段托盘未采用；后续开发延续当前外观，不将探索稿视为新的默认规范。

这些数值描述当前默认样式。应用通过公开属性、`className`、`classNames` 和颜色 tokens 适配布局，不依赖内部 CSS 类名。

Heading 保持真实 h1–h6 层级，仅 h2 默认带一笔短曲线，文章标题和其余小标题保持安静。Link 用 1.5px 下划线与适当偏移维持正文辨识度；Divider 使用 1px 轻纸线，方向、间距和装饰语义沿用原有约定。组件继承使用方字体，少量曲线与轮廓承担识别，不把整页改成手写排版。

## 交互与状态

- 键盘位置使用单层 2px 焦点提示；输入和按钮使用外轮廓，菜单与选择项使用内部高亮轮廓。避免全局样式与组件样式叠出两套焦点圈。
- 默认普通控件及选项保留至少 44px 的操作区域。Button / IconButton 的 `sm` 是紧凑的 36px 选项，不能为了塞进手机顶栏而缩小主要操作入口。
- 悬停、选中、按下和焦点分别表达不同信息。选中项获得焦点后仍保留选中状态；颜色之外保留勾选标记、开关位置和可访问状态。
- 系统强制颜色下，Button / IconButton 的按下态、SegmentedControl 的选中态、Tabs 的栏目墨线与三墨点使用系统色和可见笔线，保留选中与焦点的区别；不关闭用户的强制颜色设置。
- 禁用保留可读文字，不对整个组件降低透明度。只读字段使用独立的浅色背景，允许聚焦、复制和提交；错误由文字解释，并关联对应字段。
- 成功、提示、警告和错误按语义使用颜色，不随角色配色交换含义。Toast 适合短暂反馈，Alert 适合需要持续可见的说明；关键错误不能只靠颜色或 Tooltip 表达。
- Button 与 Spinner 共用三枚墨点，以 1.2 秒的透明度、微小下压和起落节拍表示等待，三点间隔 160ms 错开。图形只在既有图框内绘制，按钮加载时文字、尾部图标与原有宽高保持稳定；原有前图标隐藏后保留几何空间。减少动效和强制颜色时显示静止墨点，状态名称与 `aria-busy` 仍按组件职责保留。
- 动效用于确认操作、识别浮层或表达等待，操作反馈应短暂、克制。减少动效时取消控件位移和循环变化，区块场景素材保持静止；必要信息由可见文字和原生语义提供。
- 基础操作采用同一套短反馈：Button / IconButton 按下 60ms、松手 150ms，只沿既有 1px 压边回位；已选中按钮按住时仍保留内侧墨线。颜色变化保持 150ms，不增加悬停上浮、缩放或弹跳。
- Checkbox 的勾与半选短横通过 150ms 显隐和小幅展开确认切换，取消时同步收回；默认已选或半选值直接呈现，不播放入场动画。Switch 圆扣在既有 20px 行程内以 150ms 平移落位，轨道颜色同步变化，RTL 方向镜像；连续切换从当前位置回转，不排队播放。
- 上述操作只改变绘制，不改控件布局、点击区域或焦点范围；禁用不播放切换，系统减少动效时直接显示最终状态。云草等环境动效使用独立节奏，不能拖慢用户操作。
- 填写与选择沿用同一节奏：TextField / Textarea 的边框、错误底色以 150ms 过渡，键盘焦点轮廓立即可见，字段和文字不位移；动态禁用立即落到静态外观。RadioGroup 圆点以 150ms 显隐和小幅展开确认选择，圆框与选中行纸色同步；默认已选值直接呈现。SegmentedControl 保留静止纸托盘，选项底色、边框和内阴影以 150ms 同步变化，不增加滑块或缩放整个选项。
- Select 保留 150ms 展开箭头，便笺菜单以既有浮层节奏 180ms 淡入，不位移、不缩放；关闭立即完成，并取消尚未结束的入场过渡；列表高度、边缘定位和长选项换行不随动画改变。选中值与键盘高亮即时更新，关闭期间禁止继续选择；选择完成或 Escape 关闭后恢复触发器焦点，点击其他字段时保留用户的新焦点。禁用、减少动效和强制颜色直接呈现相应静态状态。

反馈族的纸面细化只调整 Alert 的语义内缘、Toast 的回执与状态印签内缘及操作区浅蓝纸面、EmptyState 默认便笺内缘。Toast 的第一行对齐、44px 关闭目标、Alert 的保存失败重试、Toast 的 8 秒计时暂停与撤销、操作后的焦点恢复和 Skeleton 的等高布局均沿用既有实现；Spinner / Skeleton 的默认造型与节拍保持。规范描述与实际验证结果分别记录，尚未执行的检查不表述为已通过。

反馈示例区分等待、空内容、加载失败与操作完成：Spinner 表达等待，Skeleton 对应最终内容的头像、标题与摘要布局；EmptyState 给出首次或无结果时的下一步，Alert 保留可处理的问题，Toast 提供短结果和可选撤销。流程、计时和焦点由调用方管理，用户已移到其他位置时不抢回焦点。普通隐藏属性在独立库样式下也应生效，同时保留 until-found 的浏览器机制，不能靠文档站的全局重置掩盖差异。

## 阅读与组合

先确定标题、正文和辅助信息的阅读顺序，再安排控件。分类标记、收藏、筛选和订阅服务于内容；同一屏不把每个操作都做成主按钮。表单标签保持明确，不用情绪化文案代替字段名称。

使用 ReadingExample 等真实文章组合检查：移除插画后是否仍然一致，16px 正文是否容易连续阅读，收藏与辅助操作是否可发现，窄屏文字是否换行，键盘焦点是否只有一套。单个组件的颜色和圆角相近，只是组合验收的一部分。

阅读组合以摘要、正文小节、原生 figure / figcaption 和一处文末 Surface 便笺建立层次，避免将每个段落做成卡片。图片用 aspectRatio 保持加载与失败区域；配图可关闭，正文和操作仍完整。切换文章将焦点带到标题，空结果恢复后回到搜索框；页内阅读链接定位便笺，同时保留文档站的 hash 路由。组件默认字阶、轮廓和间距规则不由示例另行改写。

ReadingExample 的外层阅读栏采用 68ch 上限，手机随容器自然收窄；头像、姓名与简介形成身份行，作者动作单独分组。图注与配图相隔 8px，正文段落使用 24px 布局间距，后记之后由装饰 Divider 转入收藏与反馈。以上数值属于组合布局，不强加到每个 Text、Heading 或页面，也不改变既有字号、行高和标题语义。

头像姓名回退使用主题强调色纸面与 1px 暖墨轮廓，保留 32 / 44 / 64px 空间及现有加载行为。图片失败回退用不占几何空间的 1px 轻纸内边标记区域；正常图片保持原有展示，比例、裁切、alt 与 hidden 规则独立成立。Text、Heading、Link 继续使用已有默认规则，按同篇文章中的长标题、连续正文和多行链接复核；组件保留与视觉细化分别记录。

[加载、空态与 404 场景指南](http://127.0.0.1:4175/#/guides/states) 区分行内等待、区块等待、暂无内容与未找到页面。行内加载使用共享墨点，区块示例另用三帧拔草序列，按 1.5 秒 `steps(3)` 播放，减少动效时固定首帧；1.8 秒计时器只用于模拟请求。空态提供创建、浏览或清空筛选等真实操作。404 在实际未知路由渲染 h1，在指南内渲染 h3，共用同一份场景源码；它是页面组合，没有新增公共 NotFound 组件。素材为装饰，加载说明、空态原因和导航链接由 HTML 提供。

场景素材只放在 `playground/src/examples/scenes/artwork/`，包括三帧横向 PNG、空笔记本与野餐布 PNG、地图与路牌 PNG，以及 `friends-preview/` 中的朋友群像和探头 SVG。当前两张朋友 SVG 同时供正式首页、文档外壳与开发评审使用，其他状态素材由示例按需引用；这些素材均不进入 `src/` 或默认组件库产物。完整接入提供各自 PNG 的单独下载，需保留源码中的 `./artwork/` 相对引用；[素材来源说明](../playground/src/examples/scenes/artwork/README.md)、`sources.json` 与 [SVG 绘制说明](../playground/src/examples/scenes/artwork/friends-preview/README.md) 分别记录来源和维护方式。字体与素材都不构成使用基础组件的前提。

插画和字体遵守各自许可。此项目为非官方作品，设计规则不构成 Chiikawa 官方规范，也不代表角色素材已获使用授权。

## 逐组件职责

- **Button / IconButton**：同档尺寸对齐，按尺寸选择图标图框并核对视觉中心；loading 继承名称并保留宽高。以粉色软团轮廓、内底边与主操作短底边表达按扣感，悬停、选中与焦点分别表达。
- **TextField / Select / Textarea**：统一字段字阶、标签与提示起点和焦点；TextField 图标、Select 展开触发器及菜单选中纸章与状态一致。只读可聚焦复制，禁用不提交；错误说明关联字段，长选项与多行内容自然增长。
- **Checkbox / RadioGroup / Switch**：方形勾、半选短横、圆形点、轨道位置各有职责，22px 方框与圆圈、50×30px 轨道和 44px 操作行分开维护。标签行使用 4px 水平留白，标记对齐文字第一行；Checkbox / Switch 的提示跟随标签文字，RadioGroup 的组级提示跟随组标题、单项说明跟随单项标签。RadioGroup 可用选中行使用轻纸色与 600 字重标签，禁用选中保留圆点并取消活跃纸色，选中与键盘焦点同时可辨。
- **SegmentedControl / Tabs / Pagination / Accordion**：分别表示值选择、栏目、页码与折叠内容。托盘、短墨线、圈记与圆扣保持区别，当前状态和键盘焦点同时可辨。Tabs 维持 44px 最小操作高度，短墨线宽 32px、轻转 -2°；列表间距为 8px，四周留白由焦点线宽与偏移相加，禁用选中墨线跟随禁用文字。Pagination 维持 44×44px 最小按钮，页码组换行，多位数字不压缩且自然增宽，禁用边界与不可操作的省略号保持区别。Accordion 标题使用 20px 行框及上下各 4px 留白，与 28px 圆扣对齐；默认操作区最小 44px，正文仍为 16px，上方留出 8px，沿用 4px 逻辑方向阅读起点。禁用已展开项保留箭头方向，圆扣改为中性底色；三者禁用和强制颜色下清除新增阴影，减少动效保留静态结果。

栏目与分页必须对应真正的面板和列表，不只改变一行状态文字。搜索或切换栏目后，调用方把页码重置到可用范围；翻页后可以聚焦本页标题继续阅读，输入搜索和切换标签时不抢走控件焦点。Accordion 的补充说明不替代始终可见的错误、能力边界和恢复操作。归档组合用同一份本地数据验证列表、空结果、栏目和页码的关系。

BlogArchive 的外层使用 100% 宽度与 68ch 上限，列表内已有布局间距时将 Divider 的 margin 设为 0，避免重复留白。这些只属于归档组合的栏宽与间距，不成为 Tabs、Pagination、Accordion 或 Divider 的默认值；数据、页码重置、焦点与 URL 同步仍由调用方维护。

- **DropdownMenu**：动作列表使用便笺轮廓。单行菜单项最小 44px，多行自然增高，短墨记对齐文字第一行；高亮底色、内部键盘焦点、禁用和危险动作分别表达。强制颜色下禁用文字使用系统 GrayText。
- **Popover**：可交互的补充面板使用便笺轮廓，标题下方沿用 paper-line 轻纸分隔线。44×44px 关闭按钮的中心对齐标题第一行的行框中心，长标题右侧留足操作空间。
- **Dialog**：模态任务使用信笺轮廓，标题与页脚沿用 paper-line 轻纸分隔线。无 illustration 时，44×44px 关闭按钮的中心对齐标题第一行的行框中心，标题保持桌面 24px、手机 20px；有 illustration 时维持上角 10px 顶部位置。轮廓、字阶、滚动与语义保持原有规则。
- **Tooltip**：保留小对白与独立箭头；箭头是内容 Popup 的相邻节点，data-uncentered 时隐藏，避免滚动裁切或边缘错误指向。复核长文字、可用高度与视口边缘，不为制造变化重画已有默认外观。

以上浮层的 Portal 继承主题颜色，不复制站点布局类。真实组合复核沿用“文章编辑与管理”（ArticleActions），不新增功能、场景或角色；样式细化、已有功能验收与尚待执行的检查分别记录。

保留既有 180ms 退场视觉时，已关闭节点不能继续接收键盘、点击或提交；Escape 之后立即按 Enter / Space 也不能执行旧菜单项或提交已取消的草稿。以浮层实际打开状态判断，受控父级拒绝关闭、继续保留面板时，正常操作仍须有效。视觉退场、焦点恢复和动作提交分别验证，不以指针不可点代替键盘保护。

ArticleActions 的首次保存失败、重试与草稿保留沿用现有流程；保存成功接入现有 Toast 手动关闭示例。Toast 显示时只由它播报这次结果，关闭后留下的历史文字不再次播报；关闭按钮返回手记操作入口，重新编辑则移除旧提示。示例不新增自动消失计时器、队列或撤销业务。

浮层中的编辑把草稿和已保存值分开：取消、Escape 与关闭按钮不提交数据，重开读取已保存值；失败保留输入并给出可见的恢复操作。菜单打开编辑后，返回目标是仍在页面中的操作按钮。嵌套浮层按最上层先关闭，重要说明和操作结果不能只藏在 Tooltip 中。文档的“文章编辑与管理”用一份手记验证这些组合行为，不另造一套浮层外观。

- **Text / Heading / Link / Divider**：正文先可读、标题先语义、链接保留既有下划线与焦点，轻纸分隔线服务阅读顺序；字体继承应用，栏宽和段距由组合布局维护。
- **Surface / Badge / Avatar / Image**：Surface 用轻纸边承载内容，Badge 用普通、强调和成功纸签表达轻重；Avatar 用强调色姓名回退识别作者，图片失败回退用轻纸内边标记区域，二者保留各自比例与加载行为。Image 隐藏覆盖失败回退，空 alt 保持装饰语义。

本批内容资源处理已于 2026-10-29 确认采用。加载期间保留头像和有明确比例的封面空间。Avatar 图片就绪后移除姓名回退，透明图中不再透出底下文字；姓名缩写使用前两个完整字素。Image 固定比例内的长失败说明可以从起点滚动到末尾，只有实际溢出且有可访问名称时才增加键盘入口；短说明仍居中，空 alt 装饰回退不进入键盘顺序。清空再恢复同一图片地址或 srcSet 时重新加载。博客作者介绍使用 Surface 默认白纸，外层只组织布局与留白。

- **Alert**：持续说明使用平面语义提示纸，24px 图标保留既有第一行对齐，白色上内缘与随语义色变化的浅下内缘保持平面，文字起点与字阶不变。原因、用户输入和重试动作保持可见，不靠颜色或角色表情传达唯一信息。
- **Toast**：短结果使用白纸回执，30px 状态印签与 44×44px 关闭目标的中心对齐标题第一行；默认 14px × 1.5 的标题行框为 21px，两者相对原位置上移 4.5px。文字起点、字阶、外部轮廓及关闭目标尺寸不变，回执底部和状态印签增加细内缘。操作区用浅蓝纸面、paper-line 细虚线和 12px / 8px / 8px 内留白组织后续动作，保持长文案与键盘焦点完整。
- **EmptyState**：空内容原因与下一步保持清楚，默认小纸页以白色上内缘、浅蓝下内缘和既有粉色底边呼应白纸；既有角色插画及槽位布局保留，320px 下长文本和双按钮自然换行，操作卸载后的焦点由调用方管理。
- **Spinner**：16 / 24 / 36px 三墨点与 Button 共用 1.2 秒节拍，减少动效时静止，强制颜色下仍可见；图形、尺寸与状态语义沿用既有规则。
- **Skeleton**：内容占位沿用 neutral-line、默认形状与呼吸动效，减少动效时静止。强制颜色下仅增加系统 CanvasText 的 1px 装饰内轮廓，outline-offset 为 -1px，不增加布局尺寸。
- **ThemeProvider**：管理预设与公开颜色覆盖，内部尺寸变量集中维护；配色变化不改变尺寸、结构或语义。

## 开发约束与变更顺序

1. `src/theme/theme.module.css` 是共享默认视觉 token 的唯一值源。组件引用正确语义族，不在组件内重新声明公共 `--yahha-*` 值，不增加一次性的 45 / 46px 控件档位。
2. `src/components/` 承担基础外观与状态。字号、行高、共享轮廓、焦点偏移及单行交互尺寸通过 token 使用；圆点、勾和箭头等例外必须有具体用途，机械检查采用精确范围和原因。
3. `playground/src/examples/` 负责组合、数据和布局。基准示例不得通过 `style`、`className`、`classNames` 或 `<style>` 重写组件的高度、字体、边框、配色、圆角或选中状态。公开定制入口仍供使用方应用使用；专门演示定制的例子应明确命名、说明范围并单独验证。
4. 文档站通过站点语义变量维护自身品牌色、群像场景、导航、代码块和布局，不能用覆盖组件内部 DOM 的方式“修好”示例。正文不因手机而缩回 13px，示例复制后保持相同组件规则。主要链接与 Button 共用动作视觉规则，分别保留链接导航和按钮操作语义。
5. 改规则时先核对用途和参考依据，再修改主题值、组件、文档与检查预期；改变实际尺寸或文字层次必须复核真实安装包和窄屏，不仅修改规范文字。
6. `npm run check:design` 检查未知 token、语义族、fallback 与示例外观分叉，接入总检查、CI 和本地提交前检查；坏例测试证明违规会失败。安装包回归另测实际尺寸、所有预设、状态、手机 / 粗指针、长内容和加载几何。设计细化交付使用相同内容、视口与交互状态的前后图，逐项说明可见变化，并用无文档站 CSS 的真实安装包页面复核。脚本不代替设计评审。

文档阅读层保持正文与页面说明 16px、API 与接入说明 14px、源码 13px；API 类型采用约 13px 的等宽字。辅助目录保留可读文字与足够操作区域，正文行宽与示例、表格的宽度分开处理。固定页头、侧栏与锚点留白使用同一组站点布局变量；断点隐藏导航时，焦点应回到可见入口，不能跳走仍在阅读正文的焦点。路由标题的自动聚焦也不能覆盖随后已经开始的控件操作。这些是文档站约定，不覆盖组件库默认尺寸或使用方排版。

本规范约束仓库的默认实现与默认示例，不把内部 CSS 变量承诺为公共 API，也不限制使用方通过公开样式接口定制自己的产品。

- [Radix 排版](https://www.radix-ui.com/themes/docs/theme/typography)与[间距](https://www.radix-ui.com/themes/docs/theme/spacing)：正文、控件、字阶和缩放分开定义。
- [Animal Island UI 固定版本变量](https://github.com/guokaigdg/animal-island-ui/blob/2d855fc6c1cb56cc4152290f50c43439d4a4920f/src/styles/variables.less)：主题化组件结构与尺寸分档参考；动森视觉不直接迁入 Yahha UI。
- [W3C 最小点击目标](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)与[增强点击目标](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)：分别评估操作目标和视觉尺寸。
- [朋友 SVG 素材与绘制参考](../playground/src/examples/scenes/artwork/friends-preview/README.md)：记录素材来源、绘制参考和局限；暖墨、轻粉与漫画轮廓是本库的设计选择，不声称官方背书。
