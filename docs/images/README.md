# 页面实拍

本目录用于 GitHub README 展示，截图来自当前实际运行的 Yahha UI 文档站，没有从参考网站截取或拼接角色素材。

本目录保存文档首页与组件总览的实际页面截图。2026-11-08 从当前本地源码运行的文档站重新拍摄，页面版本为 0.1.0，组件总览显示 31 个 UI 组件，另有 ThemeProvider。各图的拍摄条件如下；更新页面后按同样条件重新截取。

- [组件预览](yahha-components.png)：文档站 `#/components`，1440 × 960，设备像素比 1，保持“全部”分类与空搜索词，页面纵向滚动到 `scrollY = 1440`。完整展示布局组的 Surface、Divider，以及表单组首行的 TextField、Textarea、Select；保留站点导航，不把首屏介绍区作为组件预览。
- [文档首页](yahha-home.png)：文档站 `#/`，1440 × 900，设备像素比 1，页面顶部，默认粉色主题。

拍摄工具为 agent-browser / Chromium，地址为 `http://127.0.0.1:4175/`。等待 WenKai 字体及可见图片加载完成，再在首页使用页面本身的“暂停场景动效”按钮获得清楚的单帧；没有用 CSS 冻结页面，没有改写组件样式、内部 DOM、尺寸或人物比例，也没有缩放、裁剪或拼接截图。

页面、主题或素材变化后，按相同路由与视口重新截取实际界面，并核对字体、可见图片、运行错误与展示源码。截图中角色、图案与字体的来源见[素材与分发范围](../assets-and-distribution.md)。

这些图片仅用于仓库介绍，不进入组件安装包或默认网站构建。
