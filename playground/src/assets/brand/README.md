# Yahha UI 品牌图案

正式 Logo 为 **组件碰碰乐**。保留原稿的粉、黄、蓝组件、笑脸及 Yahha UI 字形，不添加副标题。

## 母版与导出

`yahha-ui-logo.svg` 是正式维护母版，画布比例为 847 × 280。它沿已批准 F2 的轮廓重建，字形、组件、表情和碰撞线均为真实矢量路径；无需字体或嵌入位图。移除了原候选图中的米白纸底与纹理，并整理高光和轻底边，保持图案外部及字腔透明。

- `yahha-ui-logo.png`：3388 × 1120 的 4 倍透明导出，供大尺寸使用。
- `yahha-ui-logo.webp`：同尺寸无损透明副本，供需要位图的网页使用。
- `yahha-ui-logo-on-dark.svg` / `.png`：相同轮廓，字标改为奶白色，供深色背景使用。
- `yahha-ui-logo-motion.svg`：已选 F2 的独立符号动效层，拆分上方组件、蓝块、笑脸和阴影；不含字标，不作为静态导出母版。
- `yahha-ui-favicon.svg`：独立正方形组件符号，仅包含粉、黄、蓝组件笑脸与碰撞线。
- `yahha-ui-favicon-{16,32,48,180,192,512}.png`：从符号母版直接按目标尺寸导出，四角透明。
- `yahha-ui-favicon.ico`：包含相同 16、32、48px PNG 的兼容容器。

网站默认使用 SVG 母版。图标、字形和原有高光路径保持不变，仅将字标向右平移 23 个画布单位，图文间距在桌面约为 8px（移动端同比约为 6.65px）。画布从 824 扩至 847，展示宽度按原 180px / 150px 的缩放比例同步增至约 185.02px / 154.19px，保持图案与文字原有大小。深色高对比模式通过 `picture` 选择奶白字标版本；普通白底页头使用暖棕字标。图案以真实 alpha 合成，已移除乘色混合的底色补偿。

文档站每次完整打开会从四种已确认的动效中随机播放一次，鼠标进入 Logo 时也会随机播放；同一页面内排除刚播放过的一种，播放中忽略再次触发，不叠加、不排队。1.35–1.8 秒后恢复静止姿态，右侧字标始终使用原静态图片；键盘焦点也可触发，触屏不模拟 hover。系统减少动态、页面进入后台或菜单打开时保持/恢复静态。动效仅用于站点，不进入组件安装包。

静止与播放复用同一套内联 SVG 分层和坐标；各部件静止时保留单位变换及固定合成层，避免外部 SVG 图片与内联 SVG 在小数像素下产生不同取整。右侧字标的图片裁切始终保持不变，减少动态模式显示完整静态图片。仅这些小尺寸符号部件保留合成提示，静止时没有动画或逐帧任务。

标签页使用独立 16、32px PNG，并在引用中更新缓存版本。不要把字标 SVG 的 `#symbol` 片段当作 favicon：页面内图片显示正确，不能证明浏览器标签页使用了同一裁切。独立符号 SVG 是完整文件，其他尺寸供图标场景选用。

## 再次导出

编辑 SVG 母版后，在仓库根目录运行：

```sh
node scripts/export-brand-assets.mjs
```

独立素材包保留同一导出脚本。在解压后的素材包目录中运行 `node scripts/export-brand-assets.mjs .`，可直接使用其中的两份 SVG 母版重新导出。

导出工具需要本机已有 Inkscape 和 cwebp；网站构建和组件安装包无需这些工具。PNG 由 SVG 直接渲染为透明背景，WebP 使用 `-lossless -exact`，ICO 复用 PNG 字节，不重复缩放。导出脚本只改派生文件，保留母版。

修改后核对透明比例与四角 alpha、白底/彩底/深底及强制颜色下的字标可见性，并在真实标签页检查 favicon。旧的候选图属于设计历史，当前母版以本目录的 SVG 为准。

品牌图形采用项目 MIT 许可，仅用于文档站，不进入组件安装包。
