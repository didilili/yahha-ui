# 朋友们的装饰素材

五张透明 SVG 由 `scripts/build-friends-decorations.mjs` 派生。人物完整引用 [唯一已确认造型源](../../friends-preview/source/characters.svg)，仅在外层平移、旋转和等比缩放，没有重画人物、裁出另一套头像或改变表情。

| 文件                    | 画幅      | 使用位置                                             |
| ----------------------- | --------- | ---------------------------------------------------- |
| `chiikawa-sticker.svg`  | 288 × 288 | 吉伊完整人物贴纸；建议显示 72–96px                   |
| `hachiware-sticker.svg` | 288 × 288 | 小八闭眼笑贴纸；建议显示 72–96px                     |
| `usagi-sticker.svg`     | 288 × 288 | 乌萨奇完整长耳贴纸；建议显示 72–96px                 |
| `friends-note.svg`      | 760 × 400 | 三位朋友探头的空白纸张；页面在中央叠加真实标题       |
| `friends-pattern.svg`   | 480 × 400 | 透明稀疏平铺底纹；保留完整小人物与少量花、星光、纸条 |

便笺的文字安全区为画幅中的 `x=144–620, y=205–317`，即左侧 `18.95%`、顶部 `51.25%`、宽度 `62.63%`、高度 `28%`。文字应作为 HTML 放在图片上层，保留选择、缩放与换行能力。该安全区只容纳短标题，不适合长段落。

底纹以原始 `480px 400px` 比例重复；左右边界的星光相接。作为阅读页面背景时，可将其放在单独的背景层并降低透明度，不在正文后方叠加多层密集图案。SVG 不自带底色。

贴纸边由原人物透明轮廓派生，人物绘制本身保持不变；每张 SVG 内含自身引用的全部定义，可以独立下载。装饰性引用使用空 `alt`，作为图案样张时由页面提供可读名称。素材范围与第三方说明沿用[朋友素材说明](../../friends-preview/README.md)。

在仓库根目录执行：

```sh
node scripts/build-friends-decorations.mjs
node scripts/build-friends-decorations.mjs --check
```

维护构图时修改生成脚本，不手改派生 SVG。若要改变人物模型，先按仓库约定单独评审唯一源文件，再重新同步。
