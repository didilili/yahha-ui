# 装饰元素与朋友

这组素材用于官网、阅读示例与可下载的页面组合，不进入默认组件安装包。

- `patterns/`：六种透明重复纹样；在环境面或大块留白使用，阅读与操作区域保留独立内容面。
- `titles/`：四种不含文字的标题底形，真实标题由页面提供。
- `dividers/`：五条装饰分隔线；图片本身不承担标题、状态或操作语义。
- `motifs/`：花、星光、云、芽、纸签和回形针的独立 SVG。
- `catalog.json`：以上二十一份原创装饰的名称与路径，供文档下载目录读取。
- `friends/`：从当前唯一人物源稿派生的三枚贴纸、朋友纸签与重复背景，生成方式与标题安全区域见该目录说明。

通用装饰沿用暖墨、粉蓝黄、圆端笔触与轻微不对称；以用户于 2026-11-05 选定的元素样张为基线。花、星光等通用几何由本项目绘制，没有复制参考网站的图片或矢量路径。人物沿用既有来源与说明，见 [朋友素材](../friends-preview/README.md)，这里不建立第二份人物模型。

`npm run sync:artwork` 从 `friends-preview/source/characters.svg` 派生朋友装饰，`npm run check:artwork` 检查生成一致性。通用装饰为独立源文件，修改时检查实际平铺、标题叠字和窄屏显示。

首页使用站点布局包装标题与分隔线。可复制的阅读和朋友纸签示例只依赖公开组件及随例下载的 SVG，下载时保留「示例素材」清单列出的相对目录。
