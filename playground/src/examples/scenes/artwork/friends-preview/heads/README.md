# 三位朋友的头像派生

头像只从 `../source/characters.svg` 的既有确认稿生成。保留原来的耳朵、脸颊、五官、高光、眉口和腮红；去掉身体与爪子，并在原来的头身交界补上下巴封口。人物源稿不改动。

`scripts/build-friends-heads.mjs` 随 `npm run sync:artwork` 生成九张头像：吉伊、小八、乌萨奇各有自然睁眼、闭眼笑、惊讶三个既有表情。`npm run check:artwork` 检查生成结果，测试同时核对五官定义与唯一源稿相同。

按钮、Tabs 和小型提示使用头像；完整人物、群像与空状态继续使用原全身素材。头像采用自然画幅保留比例，乌萨奇长耳完整；使用时以 `object-fit: contain` 放入 28px 图框，不裁掉耳朵，也不把全身缩进图标位置。头像作为装饰时使用空 `alt`。
