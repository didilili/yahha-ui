# 朋友们的小站 · SVG 素材

本目录为 Yahha UI 的展示专用视觉素材。人物模型参照官方角色图与数字绘画步骤重新校准，路径由本项目绘制，不是官方发布资产，不宣称为官方设计规范。未复制官网图片、其他作者的矢量路径或付费图包。

当前保留 v3 造型，暂停人物细修。当前场景、探头图及其派生场景供网站按需复用；九张人物样张用于 `friends.html` 开发评审，其中 `portraits/chiikawa-smile.svg` 还同步为博客的 `author.svg`，`friends-peek.svg` 同步为博客的 `peek.svg`。两个博客副本均由素材命令自动同步和检查。开发评审仍引用的七张历史图留在本目录，其余未引用快照已归档。素材不进入默认组件安装包。

- `friends-hero.svg`：760 × 530 的透明场景。三位朋友围着内容小站页面一起完成搭建，使用草地、花、内容卡片与小旗连接人物和任务。
- `friends-peek.svg`：440 × 170 的横向透明探头构图，用于文档页头。
- `motifs.svg`：800 × 240 的八种图案样张，包含花、嫩芽、云、星光、信封、小旗、脚印与杯子。
- `source/characters.svg`：三位角色的唯一完整造型源，保留自然睁眼、闭眼笑、惊讶三个表情；基础眼形可复用，眉、口、额纹与身体按角色分别处理。
- `portraits/`：从同一源文件生成的九张透明背景人物样张，使用相同坐标画幅，便于比较五官体量与实际小尺寸。
- `previous/`：保留初稿 `friends-hero.svg`，用于真实前后对照。
- `previous/round-2/`：保留 v2 的 `friends-hero.svg`，供历史版本切换。
- `previous/round-3/`：保留 v3 的 `friends-hero.svg`，记录当前恢复的造型来源。
- `previous/rejected-round-4/`：保留 v4 的 `friends-hero.svg` 与三位角色的 `*-bright.svg`，用于撤回版本和头脸对照，不作为当前造型。

2026-11-02 将其余 28 张未被当前代码引用的历史 SVG 归档至工作区的 `../local-archives/yahha-ui/2026-11-02-artwork-cleanup/`（相对组件库根目录）。归档按原仓库相对路径保留文件，`manifest.json` 记录字节数、SHA-256 与归档理由，归档 README 提供还原方法；这些已跟踪文件也可从 Git 历史追溯。

全部素材采用暖墨轮廓、圆形线端、平面填色与分级细节；背景透明。白色角色、蓝色猫耳与奶黄色长耳在同一场景共同出现，不承担三套主题切换。

## 校准与生成

本轮检查了眼体的饱满程度、上方高光与下方细弧、眉眼口关系；小八的中央八字额纹与点眉、乌萨奇的长弧眉与短下唇分别处理。闭眼笑使用弧线，不套睁眼高光。具体尺寸是本库候选的绘制参数，不宣称为官方比例规范。

后续先修改 `source/characters.svg`，再在组件库根目录执行：

```sh
npm run sync:artwork
npm run check:artwork
```

同步命令先从完整造型源生成两张场景与九张人物样张，再同步小日常场景和博客所需副本。每个 SVG 成品仅保留实际引用的定义及其传递依赖，仍能单独下载显示，不依赖外部 SVG 的 use 引用；完整角色与表情继续保留在源文件中。不要分别手改主场景和探头图里的五官，以免同一个角色再次出现两套比例。扶卡片的前爪也使用主模型中的 `chiikawa-grip`，在主场景与探头图中同步生成。检查命令核对人物成品、依赖裁剪与派生副本；历史对照文件保持原字节，小图案不在人物生成范围内。

v3 已有的细节调整包括：开口笑的嘴腔使用连贯外轮廓，避免水平闭合边与 W 口线重叠；下方高光减薄，腮红排线保留长短与间距差异；吉伊前爪与身体建立连接，小八耳根和额纹端点、乌萨奇耳朵与下唇分别处理。这些先前调整随 v3 保留，不代表圆润问题已经解决，也不等同于官方定量标准。

视觉核验同时查看放大图、首页实际尺寸、235px 文档探头图、导航标志和 72px 人物画布；优先检查五官可辨认、长耳未裁切、轮廓填色不外扩。造型检查与 XML／构建检查分别进行，语法正确不代表造型合格。

## 绘制参考

- [官方动画角色页](https://www.anime-chiikawa.jp/chara.html)：正面轮廓、眼睛和角色差异。
- [官方 Bakery 插画](https://chiikawabakery.jp/)：不同表情、动作与道具的共同场景。

以上用于画法研究，不是引用第三方源文件。新稿仍是本库的矢量校准候选，不声称与官方插画完全一致。

这些资源用于文档、开发评审与博客示例，不进入默认组件包或新增公共组件 API。装饰性引用使用空 `alt`；作为图案样张时由页面提供可读名称。
