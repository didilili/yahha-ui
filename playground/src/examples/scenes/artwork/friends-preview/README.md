# 朋友们的小站 · SVG 素材

本目录为 Yahha UI 的展示专用视觉素材。人物模型参照官方角色图与数字绘画步骤校准，SVG 路径由本项目绘制，不是官方发布资产，不宣称为官方设计规范。未复制官网图片、其他作者的矢量路径或付费图包。项目自有内容采用 [MIT 许可证](../../../../../../LICENSE)，第三方内容见[第三方说明](../../../../../../THIRD_PARTY_NOTICES.md)。

场景、探头图及其派生场景供文档站与组合示例按需复用；九张完整人物样张与场景共用同一份模型，由统一素材命令派生和检查。素材不进入默认组件安装包。

- `friends-hero.svg`：760 × 530 的透明场景。三位朋友围着内容小站页面一起完成搭建，使用草地、花、内容卡片与小旗连接人物和任务。
- `friends-peek.svg`：440 × 170 的横向透明探头构图，用于文档页头。
- `motifs.svg`：800 × 240 的八种图案样张，包含花、嫩芽、云、星光、信封、小旗、脚印与杯子。
- `source/characters.svg`：三位角色的唯一完整造型源，保留自然睁眼、闭眼笑、惊讶三个表情；基础眼形可复用，眉、口、额纹与身体按角色分别处理。
- `portraits/`：从同一源文件生成的九张透明背景人物样张，对应三位角色的自然睁眼、闭眼笑与惊讶表情，采用包含完整耳朵和脚部的统一画幅，供完整人物展示。
- `heads/`：从同一确认稿派生的九张头像，供按钮、Tabs 和小型提示使用；五官、耳朵与脸颊复用原路径，仅在头身交界补上下巴封口，不包含身体和爪子。由 `scripts/build-friends-heads.mjs` 生成，随统一素材命令同步和检查。

全部素材采用暖墨轮廓、圆形线端、平面填色与分级细节，背景透明。白色角色、蓝色猫耳与奶黄色长耳在同一场景共同出现，不承担三套主题切换。

## 校准与生成

当前造型基线：三位角色均采用用户于 2026-11-04 确认的造型；小八保留圆颊 r1，吉伊与乌萨奇采用同日独立评审确认的脸颊、头身与表情细化稿，原扁平 v4 仍不采用。三位角色继续共用唯一完整造型源 `source/characters.svg`，评审候选文件不作为第二份维护源。

造型维护需同时检查眼体的饱满程度、上方高光与下方细弧、眉眼口关系；小八的中央八字额纹与点眉、乌萨奇的长弧眉与短下唇分别处理。闭眼笑使用弧线，不套睁眼高光。具体尺寸是本项目的绘制参数，不宣称为官方比例规范。

先修改 `source/characters.svg`，再在组件库根目录执行：

```sh
npm run sync:artwork
npm run check:artwork
```

同步命令先从完整造型源生成两张场景与九张人物样张，再生成小日常场景。每个 SVG 成品仅保留实际引用的定义及其传递依赖，能单独下载显示，不依赖外部 SVG 的 `use` 引用；完整角色与表情保留在源文件中。不要分别手改主场景和探头图里的五官，以免同一个角色出现两套比例。扶卡片的前爪也使用主模型中的 `chiikawa-grip`，在主场景与探头图中同步生成。检查命令核对人物成品、依赖裁剪与派生文件；小图案不在人物生成范围内。

开口笑嘴腔使用连贯外轮廓，避免水平闭合边与 W 口线重叠；下方高光较薄，腮红排线保留长短与间距差异。吉伊前爪与身体相连，小八耳根和额纹端点、乌萨奇耳朵与下唇分别处理。这些细节属于项目自身的造型选择，不等同于官方定量标准。

视觉核验同时查看放大图、首页实际尺寸、235px 文档探头图、导航标志和 72px 人物画布，检查五官可辨认、长耳未裁切、轮廓填色不外扩。造型检查与 XML／构建检查分别进行，语法正确不代表造型合格。

## 绘制参考

- [官方动画角色页](https://www.anime-chiikawa.jp/chara.html)：正面轮廓、眼睛和角色差异。
- [官方 Bakery 插画](https://chiikawabakery.jp/)：不同表情、动作与道具的共同场景。
- hitogawa 的 [吉伊](https://www.hitogawa.com/chii/chiikakikata/)、[小八](https://www.hitogawa.com/chii/hachikakikata/)、[乌萨奇](https://www.hitogawa.com/chii/usagikakikata/)绘制步骤：五官定位、高光和清稿方法。
- 作者 nagano 的 [LINE 吉伊贴纸](https://store.line.me/stickershop/product/32267722/en)、[讲谈社首册封面](https://www.kodansha.co.jp/comic/products/0000349299)与 [Chiikawa Pocket](https://jp.chiikawa-pocket.com/ja/)：角色表情、正面构图与场景关系。

以上用于画法研究，不是引用第三方源文件，也不证明本项目造型与官方插画完全一致。

这些资源用于文档与组合示例，不新增公共组件 API。装饰性引用使用空 `alt`，作为图案样张时由页面提供可读名称。
