# 朋友们的小站 · SVG 素材

本目录为 Yahha UI 的展示专用视觉素材。人物模型参照官方角色图与数字绘画步骤重新校准，路径由本项目绘制，不是官方发布资产，不宣称为官方设计规范。未复制官网图片、其他作者的矢量路径或付费图包。

当前保留 v3 造型，暂停人物细修。正式首页与文档外壳复用 `friends-hero.svg`、`friends-peek.svg`；人物样张、历史版本和撤回记录仍只用于 `friends.html` 开发评审，不进入默认站点构建。素材路径继续集中维护，避免正式页与评审页各复制一份后出现造型漂移。

- `friends-hero.svg`：760 × 530 的透明场景。三位朋友围着内容小站页面一起完成搭建，使用草地、花、内容卡片与小旗连接人物和任务。
- `friends-peek.svg`：440 × 170 的横向透明探头构图，用于文档页头。
- `motifs.svg`：800 × 240 的八种图案样张，包含花、嫩芽、云、星光、信封、小旗、脚印与杯子。
- `source/characters.svg`：三位角色的唯一造型源，包含自然睁眼、闭眼笑、惊讶三个表情；基础眼形可复用，眉、口、额纹与身体按角色分别处理。
- `portraits/`：从同一源文件生成的九张透明背景人物样张，使用相同坐标画幅，便于比较五官体量与实际小尺寸。
- `previous/`：本轮重绘前的主场景与探头图，仅用于真实前后对照，不继续作为当前人物模型使用。
- `previous/round-2/`：上一轮已校准的两张场景和九张表情，保留为本轮微观细修前的真实快照，与最初草稿分开。
- `previous/round-3/`：保留的 v3 两张场景和九张表情，当前恢复版本的记录。
- `previous/rejected-round-4/`：被用户否决并撤回的 v4 扁脸素材，仅作撤回记录，不作为当前造型。

全部素材采用暖墨轮廓、圆形线端、平面填色与分级细节；背景透明。白色角色、蓝色猫耳与奶黄色长耳在同一场景共同出现，不承担三套主题切换。

## 校准与生成

本轮检查了眼体的饱满程度、上方高光与下方细弧、眉眼口关系；小八的中央八字额纹与点眉、乌萨奇的长弧眉与短下唇分别处理。闭眼笑使用弧线，不套睁眼高光。具体尺寸是本库候选的绘制参数，不宣称为官方比例规范。

后续先修改 `source/characters.svg`，再在组件库根目录执行：

```sh
node scripts/generate-friends-artwork.mjs
node scripts/generate-friends-artwork.mjs --check
```

脚本生成两张场景与九张人物样张。每个产物包含所需造型定义，能够单独下载显示，不依赖外部 SVG 的 use 引用。不要分别手改主场景和探头图里的五官，以免同一个角色再次出现两套比例。扶卡片的前爪也使用主模型中的 `chiikawa-grip`，在主场景与探头图中同步生成。小图案不在本轮人物生成范围内。

v3 已有的细节调整包括：开口笑的嘴腔使用连贯外轮廓，避免水平闭合边与 W 口线重叠；下方高光减薄，腮红排线保留长短与间距差异；吉伊前爪与身体建立连接，小八耳根和额纹端点、乌萨奇耳朵与下唇分别处理。这些先前调整随 v3 保留，不代表圆润问题已经解决，也不等同于官方定量标准。

视觉核验同时查看放大图、首页实际尺寸、235px 文档探头图、导航标志和 72px 人物画布；优先检查五官可辨认、长耳未裁切、轮廓填色不外扩。造型检查与 XML／构建检查分别进行，语法正确不代表造型合格。

## 绘制参考

- [官方动画角色页](https://www.anime-chiikawa.jp/chara.html)：正面轮廓、眼睛和角色差异。
- [官方 Bakery 插画](https://chiikawabakery.jp/)：不同表情、动作与道具的共同场景。
- hitogawa 的 [吉伊](https://www.hitogawa.com/chii/chiikakikata/)、[小八](https://www.hitogawa.com/chii/hachikakikata/)、[乌萨奇](https://www.hitogawa.com/chii/usagikakikata/)绘制步骤：五官定位、高光和清稿方法。

以上用于画法研究，不是引用第三方源文件。新稿仍是本库的矢量校准候选，不声称与官方插画完全一致。

## v4 已撤回

v4 将“圆润”错误处理为扁宽，用户已明确否决。当前人物模型与生成素材恢复 v3，保留此前其他改进。本轮暂停继续改造型；恢复旧稿不代表圆润问题已经解决。

此前查阅的作者 nagano 的 [LINE 吉伊贴纸](https://store.line.me/stickershop/product/32267722/en)、[讲谈社首册封面](https://www.kodansha.co.jp/comic/products/0000349299)、官方正面图、Bakery 和 Pocket 仍保留为参考来源；这些参考不证明 v4 的造型判断正确。

候选页默认左侧展示已撤回 v4、右侧展示已恢复 v3，头脸与五官使用相同画幅对照。v4 仅作为撤回记录，不再标为“校正成功”或“更圆润”。

这些资源仅用于 `playground/` 的展示页面，不进入默认组件包或新增公共组件 API。装饰性引用使用空 `alt`；作为图案样张时由页面提供可读名称。
