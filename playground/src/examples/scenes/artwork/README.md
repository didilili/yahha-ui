# 状态场景素材

2026-10-24 使用 Codex 内置 image_gen，以上一轮已审阅的原创同人概念板为视觉参考生成 `empty.png`。没有从官方网站截取或下载角色原图。

- `empty.png`：透明的空笔记本与野餐布场景。
- `sources.json`：实际尺寸、哈希和生成来源。

提示词约束：非官方Chiikawa同人；简单二维深棕圆端墨线、白色/浅蓝/奶黄主体、小粉腮红、稀疏草地；禁止3D、塑料质感、背景纸、字母/标题/数字和水印，要求真正透明背景与空本/空野餐布。

这些图只在playground场景中按需加载，通过示例“完整接入”单独下载；`src/`不引用，默认npm产物不包含它们。AI生成不构成角色授权证明，本项目尚未核验这些角色素材的再发布或商业使用许可；本轮没有对外发布。不得把该说明解释为已有开源素材许可证。

新增的 [小日常 SVG](little-days/README.md) 是独立绘制的生活道具，与上述 AI 角色插图分开记录。
该目录是原始路径的唯一来源，`little-days-*.svg` 为脚本派生的示例文件；修改后执行
`npm run sync:artwork`，并用 `npm run check:artwork` 检查静态、动效与博客副本一致性。
