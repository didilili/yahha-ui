# 小日常 SVG · 生活道具与状态

首批四张生活道具共享暖墨轮廓、奶白纸面、轻粉与花形细节，第二批延续它们表达搜索、
收藏完成、加载失败与 404。道具由本项目绘制；404 从既有 v3 模型组合三位朋友，
不修改角色路径或比例。这些素材用于文档与网站组合，不新增公共组件，也不进入默认安装包。

| 源文件                           | 画幅      | 用途与动作                                                     |
| -------------------------------- | --------- | -------------------------------------------------------------- |
| `bookmark.svg`                   | 24 × 24   | 折角书签，按 18 / 20 / 22px 检查；原生 SVG 使用 currentColor。 |
| `tea-cup.svg`                    | 96 × 96   | 花印茶杯，三缕蒸汽在 2.4 秒内错峰轻升。                        |
| `page-wait.svg`                  | 240 × 168 | 手记、书签与草芽，单页沿书脊在 2.8 秒内翻合。                  |
| `empty-collection.svg`           | 240 × 180 | 布袋与空白纸签，静态空收藏场景。                               |
| `search-empty.svg`               | 240 × 180 | 草芽、放大镜和空纸条，静态搜索无结果。                         |
| `collection-saved.svg`           | 240 × 180 | 复用空收藏口袋，星星纸签在 760ms 内落入一次，随后停稳。        |
| `load-error.svg`                 | 240 × 180 | 便笺纸角在 480ms 内轻摆一次，最终仍显示完整便笺。              |
| `source/friends-lost-layout.svg` | 480 × 320 | 三位朋友围着地图找路的构图源，原角色定义由同步脚本原样注入。   |

所有源文件默认 `data-motion="off"`。热茶、翻页、收藏完成与失败通过同一源文件派生
`data-motion="on"` 版本。前两项用于受控循环，后两项只播放一次；开启减少动效时停止
动画并保留完整静帧。SVG 不嵌位图、脚本或外部引用；404 仅引用文件自身定义的角色组。

## 同步与交付

```sh
npm run sync:artwork
npm run check:artwork
```

同步命令先生成当前朋友场景与人物样张，再生成十二个小日常扁平 SVG，以及从书签路径派生的博客
`BookmarkMark.tsx`。404 构图模板的定义占位会注入
`friends-preview/source/characters.svg` 中实际引用的既有模型及其传递依赖；完整人物与表情保留在源文件，下载得到完整独立 SVG，
不需要另找人物文件。不要分别修改派生文件。文档的两个例子各自提供原样源码和所需六个素材，
静态与动效文件都可单独作为图片引用。

欢迎场景另由 `scripts/build-friends-welcome.mjs` 从既有主场景与人物源派生两份 SVG，
因此文档下载总数为十四份。成品仅保留所需定义，原始模型保持不变，只在派生场景中分离小八前爪并增加环境动效分组。
`FriendsWelcome.tsx` 使用原生 SVG 控制真实的暂停、继续和招呼重播；博客版本由同步脚本复制，
只迁移一处资源导入路径，控制逻辑保持一致。

环境中的云、草芽与花按轻缓节奏循环，前爪在 1.8 秒内挥两下后回到原位。
首次主要画面可见后开始，完全离屏或页面隐藏时暂停，减少动效时保留完整静帧。
重播只重建前爪组，环境保留原时间线；手机减少次要植物与远云运动。

博客只同步当前实际导入的六份 SVG：静态热茶、空收藏、搜索空结果、收藏成功动效、404 与静态欢迎场景。书签通过 `BookmarkMark.tsx` 复用路径，不再额外复制书签 SVG；未使用的静态或动效副本不保留在博客目录。翻页和失败动效仍供文档现有等待与恢复流程使用，文档的十四份下载保持完整。

静态博客不制造加载等待；首页欢迎控制器按需启用静态 SVG 内的动效。
状态文字、恢复入口、焦点和点击目标仍由现有组件及调用方处理。

参考网站用于研究共同活动、形状复用与动效分工，没有复制它们的图片或矢量路径。
