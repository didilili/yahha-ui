# 默认设计规范示例

这两份自包含示例直接使用组件库默认样式。此前的左右候选对照已撤回，不保留局部 flat 主题、46px 字段或另一套选中样式。

- `DesignBaseline.tsx`：区域名“规范表单”。覆盖昵称、邮箱错误恢复、分类 Select、只读 / 禁用、保存加载和收藏。按钮紧凑 / 常规 / 宽松档使用公开 size 属性，实际36 / 44 / 52px，字段短单行为44px。文字换行允许增长。
- `DesignReading.tsx`：区域名“规范阅读”。Text 默认16px正文；既有栏目、筛选、目录、收藏与空态直接复用组件。条件内容卸载后恢复焦点，页内链接不破坏宿主 hash 路由。

每个 TSX 包含公开组件导入、CSS入口、固定粉色预设（pink）和业务状态。复制单文件即可运行，不依赖额外CSS、角色图片、字体或展示依赖。没有网络请求、持久化或真实发布。

示例只为容器设置布局，不覆盖公开组件的高度、字体、边框、颜色、圆角或状态。设计检查拒绝样式分叉；尺寸、排版与状态的唯一实现保留在src。

评审需覆盖真实操作、Tab / 方向键、窄屏 / 粗指针、减少动效、系统强制颜色与长内容；代码能编译不代表视觉已通过评审。完整规则见[设计语言](../../../../docs/design-language.md)。
